# RIGGO demo web para iPhone — SIN NUBE
La página `docs/index.html` es una **demo local**, no el backend real. No se acreditan visitas en Firestore ni se lee/escribe NFC desde Safari. La versión nube está preparada en los archivos V12.3 y requiere una conexión Firebase auténtica. Si GitHub Pages está habilitado, puede abrirse en Safari y agregarse a la pantalla de inicio.
